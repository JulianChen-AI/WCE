# 微信聊天档案

**把群聊存下来。要找的，一搜就到。**

文字、图片、语音、合并转发，整理成本机档案。按人、日期、关键词筛选，导出网页或文件。

## 让你的 Agent 来装

把仓库链接交给编程 Agent，再说：

> 帮我安装这个项目的 Mac 版。先读 `docs/INSTALL.md`，检查环境，再安装并打开。不要上传我的聊天或密钥。

面向 **M 系列 Mac，macOS 13+**。当前是待发布候选版，不承诺所有微信版本兼容。

首次读取仍需本人确认系统权限、导入已有数据库密钥；本版不自动取密钥。缺失的媒体不保证能恢复。
