# 使用

1. 打开 App；未连接时点“复制连接提示词”，交给能操作本机的 Agent 按 docs/INSTALL.md 完成授权与已有密钥验证。成功后点“我已完成，重新检测”；普通用户不用填写高级字段。无可用密钥时会明确提示阻碍，不保证自动获取。
2. 选择群聊，生成本机现存消息的档案。
3. 在档案内搜索，按成员、日期或类型筛选，查看图片、语音、引用及合并转发，再导出需要的内容。

只处理有权处理的聊天。程序不自动获取密钥、不修改微信。未同步或已删除的消息、缺失媒体不保证恢复。语音转文字可选，首次会下载模型，机器转写可能出错。

目标微信版本为 4.1.13；仍需核对完整构建号、数据库结构及实际读取效果。错误反馈只需系统版本、微信版本和脱敏错误，不发送密钥、数据库、聊天原文或附件。

再次启动：若选择桌面入口，双击 Agent 交付的桌面快捷方式；否则打开已安装的 WeChatChatkit.app，或使用 Agent 核实并交付的源码启动命令。先登录微信，等待浏览器打开并保持后台运行；不要依赖上一次的临时端口。
