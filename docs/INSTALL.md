# Mac 安装

面向 Apple Silicon（M 系列）Mac，要求 macOS 13 或更新版本。当前走源码构建，不要求用户自己操作命令；可把仓库链接和本说明交给编程 Agent。

## 给 Agent

0. 开始先询问用户是否需要 App 加桌面双击启动入口，等待回答后再安装；不需要则保留现有启动方式。复用已有 App，桌面只建指向它的替身/链接，不复制 App、不覆盖同名文件，遵守用户桌面目录约定。完成后说明确切图标/路径或核实过的源码启动命令；端口可能变化，不把临时网址作为长期启动入口。
1. 检查源码来源、`LICENSE` 和第三方声明。只在有权使用的设备上安装。
2. 确认 macOS、原生 arm64 和 Python 3.11。缺 Python 时，优先使用用户已安装的包管理器；如已有 uv，可运行 `uv python install 3.11`，再把 `uv python find 3.11` 返回的解释器路径设为 `CHATKIT_PYTHON`。不要擅自安装包管理器或索取账号密码。
3. 在仓库根目录先运行 `bash install.command --check`。检查不安装依赖、不创建环境、不改用户配置。
4. 运行 `bash install.command`。它创建仓库内独立虚拟环境，联网下载 Python 依赖，在本机构建 App，安装到 `~/Applications/WeChatChatkit.app` 并打开。全程不需要 sudo。
5. 若发现已有同名 App，停止并告知用户；脚本不会覆盖。需要并存时，用 `--app-dir` 指定新的绝对目录。
6. 安装后继续完成下方“首次连接”，不能把 App 已打开当作任务完成。无法继续时，界面的“复制连接提示词”用于让另一个能操作本机的 Agent 接着协助。

可选：`--no-open` 只安装不启动；`--app-dir /absolute/path` 指定应用目录。若解释器不在 PATH，设置 `CHATKIT_PYTHON=/absolute/path/to/python3.11`。

## 遇到阻碍

- 网络或构建失败：保留错误输出，解决后重跑。未成功构建不会安装半成品。
- 系统权限弹窗：由用户确认，不关闭 SIP、Gatekeeper，不移除隔离标记，不修改或重签名微信。
- 没有数据库密钥：按下方首次连接流程检查可复用信息与可用的本机获取方式；没有适配方式时明确报告缺口，不宣称连接成功。
- 只有 Intel Mac、Windows 或不兼容的微信版本：不要宣称支持。

## 数据与卸载

用户配置、密钥与默认档案在 `~/Library/Application Support/WeChatChatkit`；模型首次使用时需联网下载。安装不会导入开发者配置或读取其聊天。

卸载时由用户确认移除自己安装的 App。聊天档案和密钥目录默认保留，不自动删除。候选版尚未完成独立干净 Mac 的端到端验证；本机构建成功不等于签名、公证或所有版本兼容。

## 首次连接：给安装与接入 Agent

### 标准连接流程

页面“复制连接提示词”包含完整分步操作，执行顺序固定为：绑定项目与 App/PID/端口 → 分开验证宿主与 App 读取权限 → 有限定位已有候选密钥 → 全候选逐库验证 → 同一实例保存与接口验收。不要因排障重复安装或另建 App。

- 安装只在缺少 App 时执行；已有工作页面先核对其进程路径。
- 完全磁盘访问权限由用户授予确切 App 路径；Agent 宿主的权限不代表 App 的权限。授权后重启目标实例；多份同名 App 时优先排除授权错副本，不读取/修改 TCC 数据库。
- 仅检查默认用户配置、本人明确提供的备份与 portable.py 声明的旧配置。候选仅在内存流转，不输出、不提交。公开项目没有通用密钥获取器；无候选时立即交付具体阻碍，不无限搜索或自动安装采集工具。
- 复用 run.connect / launcher.connect_aux；联系人、会话、实际消息分库分别尝试完整候选集合，使用只读查询，不假定共用一把密钥。必需库失败须单独报告；不以无关迁移库失败否定全部连接。
- 同一实例 POST /api/setup（带该实例 Origin），再 GET /api/accounts 与 /api/groups，仅报告状态与数量。配置保存成功不是读取成功；零条也可能合法。连接不等于媒体解密、语音转写或导出已验证。
- 同一错误最多原样重试一次；等待授权后从断点继续。未经同意不结束其他进程、重装、覆盖配置、下载语音模型或导出。

本机 WorkBuddy 案例的主要绕路：已有环境仍重建 App；宿主可读被误当成 App 可读；同名旧副本获授权；用联系人库的一把密钥测试其他库。最终成功依赖已有本人候选密钥和正确 App 授权，不是全新无密钥安装的成功案例。具体候选编号、账号及开发者路径不得写死到公共流程。

聊天记录与密钥只在本机处理、保存，不主动上传聊天内容；不关闭 SIP、Gatekeeper，不修改或重签名微信。导出档案包含隐私，不能承诺任何情况下“绝不泄漏”。
