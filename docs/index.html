可以做什么

  • 选对聊天对象：区分联系人、群聊、公众号、服务号与其他账号；显示可用头像，按最近会话排序。
  • 一次导出多个聊天：勾选联系人或群聊，分别生成聊天档案。
  • 查找旧消息：按成员、日期和消息类型筛选，浏览引用与合并转发。
  • 一起整理媒体：保留本机可获取的图片、语音、视频、表情和文件；可选本机语音转文字。

让你的 Agent 来装

将下面这段话交给能操作本机的编程 Agent。它会先询问你是否需要 App 和桌面双击入口，再按项目说明继续安装、检查和连接。

阅读安装说明

公开项目没有通用自动密钥获取器。没有本人已有的有效密钥时，Agent 应明确说明阻碍，不应假装已连接或无边界尝试工具。普通用户不需要把高级设置中的所有字段填满。

从连接到导出

  1. 连接本机微信。登录微信，完成必要授权和密钥验证。未连好时，工具页面可复制更详细的连接提示词。
  2. 选好聊天对象。切换账号分类，搜索并勾选联系人或群聊。
  3. 生成自己的档案。导出后本机浏览、筛选与检索；没有选择，不自动导出。

下次使用时双击桌面入口，或打开实际安装的 App。启动后等待浏览器打开，并保留后台进程。端口可能变化，不要把临时网址当成长期启动入口。

当前状态与边界

目前为 Apple Silicon Mac 测试版，使用 Python 3.11。文档目标微信版本为 4.1.13；其他版本需要实际验证，暂不宣称支持 Windows 或 Intel Mac。

只整理本机现存且可读取的历史，不保证找回已删除消息、未同步内容或缺失媒体。语音转写首次需要联网下载模型，转写结果可能有误。封面中的联系人与界面为虚构示意，不是真实聊天截图。

隐私与许可

仅处理本人有权处理的数据。不要把密钥、数据库或导出档案放进公开仓库，也不要发给外部 Agent。本机处理不等于任何情况下“绝不泄漏”。
